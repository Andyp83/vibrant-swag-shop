Swiss Peak Heritage Pen Set

Precision Swiss Peak pen set which features a twist-action ball pen and a rolling ball pen that are beautifully presented in a Swiss Peak gift box. They laser engrave to a brass finish and have subtle Swiss Peak branding on the centre ring and cap.
