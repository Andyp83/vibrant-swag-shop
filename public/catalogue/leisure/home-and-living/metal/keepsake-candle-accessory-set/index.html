Keepsake Candle Accessory Set

PLU 126688 · Home & Living · Metal

Extend the life and improve the performance of candles with the timeless Keepsake Candle Accessory Set. A wick trimmer ensures that wicks can be kept tidy, reducing excess smoke. Extinguish candles using the snuffer or the wick dipper, which can be used to dip the lit wick into the liquid wax, eliminating any smoke. The elegant tray keeps the accessories tidily organised. Made from stainless steel with a matte black finish, this set is presented in a natural gift box with a Keepsake branded sleeve, making it a perfect gift.
