Mini Fondue Set

Mini ceramic fondue set that includes two stainless steel serving skewers with polypropylene handles. This novel fondue set is sure to provide engaging entertainment for guests at dinners or parties. The set includes a tealight candle holder, a bowl and two skewers. Tealight candles are not included.
