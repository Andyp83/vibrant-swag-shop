Megabyte USB Hub

PLU 124144 · Tech Accessories · Metal

Convenient USB hub with three USB-A output ports and one Type-C output. The USB-A 2.0 output port and Type-C output port provides up to 480MB/s transfer speed, while the USB-A 3.0 output port provides up to 5GB/s data transfer speed. The Type-C input cable comes with a USB-A adaptor, so it is suitable for most PCs and laptops. A Velcro cable tie helps to keep the hub and cables together
