Zodiac Charging Cable

PLU 116036 · Charging Cables · Metal

Trendy mobile charging cable which can be used to charge most phones. It has a translucent LED insert that lights up when it is in use and four different connectors. Zodiac has a USB connector cable, a Micro-B connector, a Lightning connector and a USB Type-C connector. This device is for charging only and is not designed for data connections. It can be customised with full colour branding and the choice of seven different coloured translucent inserts.
