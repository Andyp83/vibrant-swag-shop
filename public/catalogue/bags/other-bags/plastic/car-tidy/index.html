Reusable rubbish bag which is ideal for use in cars, boats, trucks, heavy machinery cabs etc. It is manufactured from robust 210D polyester and features a secure Velcro base closure which makes emptying it very easy. Other features include an adjustable woven strap with a snap lock release and an expandable opening which allows the bag to hold larger items like bottles and cans. A simple instruction leaflet is included.
